#_newSatelite

Repositório de aprendizagem de programação em Lua

## Execução:

Graças à configuração do VS com ```tasks.json```, para compilar os programas .lua, basta utilizar o comando Ctrl+Shift+B

Caso use o VS Code do Codespaces

- Use os comandos de atualização, `sudo apt update`, e de instalação do lua, `sudo apt install lua5.5 -y`
- Mude o diretório até onde está o arquivo .lua que quer compilar
- Basta comandar `lua <nome-do-arquivo>.lua` e o programa irá compilar.
